발행 요청 방법

별도 비밀번호를 만들 필요 없이 GitHub 계정을 사용합니다.

휴대폰에서 요청하기

  1. 글을 읽고 목록 또는 본문 아래의 발행 요청을 누르세요.
  2. GitHub에서 Map5233 계정으로 로그인하세요. 비밀번호는 github.com 화면에만 입력합니다.
  3. 미리 채워진 제목과 글 정보를 확인한 뒤 Submit new issue 또는 Create를 누르세요. 요청 작성 화면만 열어서는 저장되지 않습니다.
  4. 검토함으로 돌아와 상태 확인을 누르면 저장된 요청을 볼 수 있습니다.

요청과 발행은 다릅니다

요청은 GitHub에 기록됩니다. 이 버튼이 글을 바로 병합하거나 배포하지는 않습니다.

요청 목록 확인 후 실제 발행은 별도로 처리합니다. 이 채팅에서 “발행 요청 확인해 줘”라고 말씀하시면 저장된 요청을 확인할 수 있습니다.

요청을 취소하거나 바꾸려면

저장된 요청 보기 → Close issue로 요청을 닫으세요. 닫힌 요청은 발행 대기 대상으로 취급하지 않습니다. 내용을 바꾸고 싶으면 기존 요청을 닫고 검토함에서 새로 제출하세요.

본문·댓글·라벨 등 요청 기록이 변경되면 재확인이 필요할 수 있습니다. 글 자체가 수정되면 새 버전을 읽은 뒤 다시 요청해야 합니다.

누가 요청할 수 있나요?

GitHub가 확인한 Map5233 계정의 고정 사용자 ID와 글 버전이 맞는 기록만 유효한 요청으로 인식합니다. 다른 사람이 공개 저장소에 글을 남겨도 발행 요청으로 처리하지 않습니다.

공개 기록 안내

저장소가 공개되어 있어 요청 제목·내용·GitHub 계정명이 공개됩니다. 비밀번호, 연락처, 아이 이름이나 사진 등 개인정보는 적지 마세요.
