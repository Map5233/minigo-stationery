# 미니고 브랜드 홈페이지

학용품 브랜드 **미니고**를 위한 반응형 한국어 정적 사이트입니다. 빌드 도구나 프레임워크 없이 HTML, CSS, JavaScript만 사용했습니다.

## 파일 구성

- `index.html` — 홈, 내 소개, 제품, 이야기, 연락하기 섹션
- `styles.css` — 반응형 레이아웃과 브랜드 스타일
- `script.js` — 모바일 메뉴, 스크롤 내비게이션, 등장 효과
- `assets/minigo-stationery-set.png` — 대표 제품 이미지
- `DESIGN.md` — 이후 수정을 위한 디자인 기준

## 로컬에서 보기

`index.html`을 브라우저에서 바로 열면 됩니다. 별도의 설치나 빌드 과정은 없습니다.

## 내용 바꾸기

현재 제품명, 이메일, 블로그 글은 자연스러운 임시 내용입니다. `index.html`에서 원하는 문구로 교체할 수 있습니다.

## 이미지 제작 정보

사이트의 대표 이미지는 기본 이미지 생성 도구로 제작했습니다. 최종 프롬프트는 네이비 노트, 메모지, 펜, 자와 지우개를 종이 흰색 배경 위에 정돈한 실용적이고 신뢰감 있는 한국 문구 카탈로그 스타일의 제품 사진이며, 로고·문자·워터마크는 제외하도록 지정했습니다.
