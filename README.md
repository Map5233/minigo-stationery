# 미니고 브랜드 홈페이지

학용품 브랜드 **미니고**를 위한 반응형 한국어 정적 사이트입니다. 빌드 도구나 프레임워크 없이 HTML, CSS, JavaScript만 사용했습니다.

## 디자인 방향

- 활기찬 팝 에디토리얼 무드
- Cream `#F6F1E7`, Ink `#1C1A17`, Pop Orange `#FF4F2E`의 3색 시스템
- 풀스크린 제품 사진과 굵은 고딕 헤드라인
- 섹션마다 15vh 이상의 여백과 38ch 이하 본문 폭
- 히어로의 느린 줌 한 가지 모션만 사용
- `prefers-reduced-motion`과 375px 모바일 화면 대응

## 파일 구성

- `index.html` — 홈, 제품, 이야기, 연락하기
- `about.html` — 창업자 소개와 브랜드 스토리
- `styles.css` — 브랜드 토큰, 편집 레이아웃, 반응형 스타일
- `script.js` — 접근 가능한 모바일 메뉴와 연도 표시
- `assets/minigo-pop-hero.png` — 와이드 대표 제품 사진
- `assets/minigo-pop-detail.png` — 세로 제품 디테일 사진
- `DESIGN.md` — 이후 작업을 위한 디자인 기준

## 로컬에서 보기

`index.html`을 브라우저에서 직접 열거나 간단한 정적 서버로 확인할 수 있습니다. 설치나 빌드 과정은 없습니다.

## 임시 내용

현재 제품명, 규격, 이메일, 이야기 글은 이후 교체할 수 있는 자연스러운 임시 문구입니다.

## 이미지 제작 정보

제품 사진은 기본 이미지 생성 도구를 사용해 기존 미니고 제품군의 정체성을 유지하면서 Cream·Ink·Pop Orange의 팝 에디토리얼 캠페인 사진으로 제작했습니다. 로고, 문자, 사람, 워터마크는 포함하지 않았습니다.
